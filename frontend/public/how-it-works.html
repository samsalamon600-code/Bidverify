How the BidVerify Works

Role-based workflows for Procurement Officers, Offering Companies, and the Automated AI/ML Verification Pipeline.

ROLE A
Procurement Officer Workflow
  1. Login & Dashboard: View KPIs across active tenders, submitted bids, high-risk alerts, and pending reviews.
  2. Create & Publish Tender: Define technical thresholds (e.g., RAM >= 16 GB, SSD >= 512 GB), MII local content %, and mandatory documents.
  3. Trigger AI Compliance Verification: Run the automated Document Intelligence, compliance rule engine, and statistical risk analyzer on any submitted bid.
  4. Inspect Evidence & Anomalies: View exact document page numbers, extracted text snippets, and anomaly explanations.
  5. Human-in-the-Loop Review: Record officer comments and update status to Reviewed, Requires Clarification, or Verified.
  6. Generate Compliance PDF Report: Download the signed PDF compliance report and audit log.
ROLE B
Offering Company / Bidder Workflow
  1. Register & Maintain Statutory Profile: Enter GSTIN, Corporate PAN, Udyam Registration Number, CIN, and Make in India local content %.
  2. Browse GeM Tenders: Inspect open tenders, eligibility criteria, technical parameters, and required certificates.
  3. Submit Bid & Specifications: Provide financial quote, warranty years, delivery schedule, and offered technical specifications.
  4. Upload Multi-Document Package: Upload Technical Bid, GST Certificate, PAN, Udyam Certificate, OEM MAF, and EPFO/ESIC documents.
  5. Track Verification & Clarifications: Monitor real-time compliance verification status and respond to any issues flagged by the officer.
AUTOMATED PIPELINE
System Processing Pipeline
  1. File Validation: Enforces extension whitelist, max file size, 0-byte empty file rejection, and duplicate filename checks.
  2. Intelligent Document Processing: Document image preprocessing, noise filtering, and high-accuracy text extraction.
  3. Multi-Signal Document Classification: Uses pattern signatures, keyword density, and similarity matching to classify documents accurately.
  4. Compliance & Inconsistency Engine: Compares tender requirements vs extracted values and detects cross-document discrepancies.
  5. Statistical Risk & Anomaly Scoring: Flags statistical outliers (such as 30-year warranty claims) for mandatory human review.
